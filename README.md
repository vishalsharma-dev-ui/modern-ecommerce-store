# 🛍️ AuraTech - Modern Minimalist E-Commerce Platform

[![Tech Stack](https://img.shields.io/badge/Stack-JavaScript%20%7C%20TailwindCSS%20%7C%20HTML5-indigo.svg)](https://github.com/)
[![State Management](https://img.shields.io/badge/Architecture-Reactive%20State%20Cart-blueviolet.svg)](https://github.com/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](https://github.com/)

A modern, responsive, and performance-tuned e-commerce storefront web application. Engineered with vanilla JavaScript component-based state architecture, instant cart drawer management, category-level product filtering, dynamic subtotal calculations, and simulated payment gateway (Razorpay) checkout flow.

---

## 🌟 Key Features

- **Reactive Shopping Cart:** Interactive slide-over cart drawer with dynamic item quantity increments, decrements, item removals, and real-time subtotal updates.
- **Category Filter System:** Filter hardware gear by categories (Audio, Smart Wearables, Workspace Accessories) with zero latency.
- **Payment Gateway Integration Simulation:** Seamless modal checkout workflow simulating Razorpay transaction authorization.
- **Pixel-Perfect Responsive UI:** Built with modern Tailwind CSS utility classes, fully responsive across all device breakpoints.
- **Accessible & Clean Code:** Modular functions, semantic HTML5 structure, and accessible button/modal interaction states.

---

## 🛠️ Technology Stack

- **Frontend:** HTML5, CSS3, Modern JavaScript (ES6+ State & Array Methods)
- **Styling:** Tailwind CSS (Modern Utility-First Design System)
- **Icons:** Lucide Icons
- **Typography:** Inter (Google Fonts)
